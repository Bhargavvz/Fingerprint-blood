## **🛠️ Quick Start (5 minutes)**

### **1. Setup Everything**
```bash
cd /Users/harivarshraoailneni/Desktop/FingerPrint
./setup-complete.sh
```

### **2. Configure Firebase**
1. Go to [Firebase Console](https://console.firebase.google.com/)
2. Create project: `bloodscan-production`
3. Enable Authentication + Firestore
4. Download service account → `backend/firebase-credentials.json`
5. Update `frontend/config/firebase.ts` with web config
6. Update `backend/.env` with project ID

### **3. Train AI Models**
```bash
cd backend
python train_models.py --epochs 50
```

### **4. Test Complete System**
```bash
# Backend API
curl http://localhost:8000/health/

# Frontend
cd frontend
npm run dev
```
